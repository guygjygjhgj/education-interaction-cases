02 / 问题筛选

先区分已知问题与现场假设

“门槛”包括真实的设计难点与验证条件；不能仅用加一个AI识别功能来代替问题定义。

观察中断：看到了，却来不及留下证据

获奖案例直接提出：B01。

要去现场确认
松雅湖用户需要在望远镜、手机、识别资料之间切换多少次？中断是否真的导致丢失目标？
设计门槛
要在小视野和短暂观察机会内安排拍摄、识别与解释，避免信息遮住目标。
怎么验证
记录一次完整观察中的工具切换、目标丢失和恢复时间。

稳定观看：放大之后，看不稳或难以持续

产品机制与官方问题说明：B02、B05。

要去现场确认
新手的失败来自抖动、调焦、握持疲劳，还是一开始没有把鸟放进视野？
设计门槛
辨清光学问题与操作问题，才能决定需要稳像、支撑还是更清楚的引导。
怎么验证
借用现成望远镜，比较支撑方式与操作指引；记录看清目标所需时间和失败原因。

共同观看：讲解者指的鸟，其他人未必找到

待验证假设；由家庭活动与观察设施情境提出，尚无松雅湖量化证据。

要去现场确认
亲子、同伴或讲师带队时，大家看到的是否真是同一只、同一群鸟？
设计门槛
把“那边那只”转换为可理解的方位、特征与共享画面；移动目标和多人视角使配准更难。
怎么验证
让同伴分别指出目标，用照片或讲师复核；记录同目标一致率和找到目标的时间。

从名称到理解：识别结果怎样变成自然学习

当地有辨识与记录教学；BP01、BP02提供自然教育研究依据。

要去现场确认
用户知道鸟名后，能否指出辨识特征，解释它正在做什么？
设计门槛
按当下可见证据给出少量解释；AI应呈现候选、辨识点与不确定性，这属于拟设计机制。
怎么验证
比较只给名称与给可见特征两种原型，检查特征辨别、延时记忆与求助行为。

保护边界：好的观看体验不能以更近的接近为代价

生态研究BP03、BP06支持需要分情境考虑；不是松雅湖已测得的固定阈值。

要去现场确认
管理人员允许在哪里停留、设置设备和组织人群？哪些时段、活动需要改变？
设计门槛
生态约束、视线和体验需要共同设计，设备安装与运营需获得场地许可。
怎么验证
先访谈管理者和本地鸟类工作者，再观察既有游客活动；不通过逼近或惊飞鸟类来测试。

B01

重点 · 观察与记录的连续性

Canon PowerShot ZOOM

iF DESIGN AWARD 2021 金奖

Canon · 实体产品；获奖年份另由佳能2021年官方公告交叉核对。

具体痛点
传统望远镜与相机分别承担观察和拍摄，转换设备时可能错过正在发生的动作。这个任务冲突由iF项目说明直接提出。
操作 → 反馈
保持取景观察远处对象 → 在需要的时刻直接拍摄；同一手持设备承接两项任务。
值得借鉴
减少“先放下观察工具，再拿起拍摄工具”的中断；左右手均可直觉操作。
设计门槛
设计难点是观看姿势、按键盲操作与拍摄时机之间的协调；迁移到AI观鸟还需解决识别触发时机和结果遮挡视野的问题。
与松雅湖的关系及AI证据

适合研究“看鸟—取证—识别”能否连续完成。获奖依据没有证明它能自动识鸟，也不等于其画质适合所有远距离水鸟。

未从获奖页确认AI识鸟；这是任务整合与实体交互案例。

B02

重点 · 稳定观看与持续握持

FUJINON TECHNO-STABI TS-L 1640 / 2040

IDEA 2025 Gold；另有iF获奖项目记录

FUJIFILM · Taiki Saito · 实体产品；IDEA奖级由IDSA官方总库与项目页共同核对。

具体痛点
高倍率观察需要稳定画面，而常见防抖望远镜的体积和重量又限制便携、长时间手持使用。
操作 → 反馈
手持望远镜观察 → 防抖系统修正振动 → 持续获得较稳定的放大视野。
值得借鉴
把原本受专业设备体量限制的稳定观察能力，整合进适合户外携带和握持的机身。
设计门槛
光学、稳像、供电与重量互相牵制，是实质工程门槛。设计课题可以借用现成光学设备，重点验证握持、支撑和调节流程。
与松雅湖的关系及AI证据

支持从远处持续观察的体验目标；并未证明在松雅湖能识别某种鸟，或已量化减少人为干扰。

已核稳像技术；稳像不应自动标为AI，也不是“具身智能”。

B03

重点 · 多种感知模式的操作负担

HABROK 4K 2.0 多光谱双筒望远镜

iF DESIGN AWARD 获奖项目；奖年未核

Hangzhou Microimage Software / HIKMICRO · 实体产品；官网可读文字标明2025年上市，未以此推断获奖年份。

具体痛点
数字观察与热成像具有不同用途；如果切换模式、重新调焦复杂，会增加寻找和保持观察目标的操作负担。这是本次依据产品机制提炼的痛点。
操作 → 反馈
轻推后部控制件切换数字 / 热成像视图 → 单手调焦 → 继续观察。
值得借鉴
让多种传感能力沿用熟悉的双筒握持与调焦方式，而不是要求用户在多套设备之间切换。
设计门槛
模式状态必须清楚，手持时应能辨别控制件；不同光照、水面、遮挡和温差下的实际效果需要现场测试。
与松雅湖的关系及AI证据

可借鉴模式切换、状态提示与单手操作；多光谱传感不等于鸟种识别，也不能直接照搬为面向儿童的观鸟产品。

已核数字 / 热成像两种视图；未从该获奖页确认自动识鸟。

B04

重点 · 进入、停留与观察的空间交互

RISE, a coastal observation platform

ASLA 2017 Student Awards · Award of Excellence, Student Collaboration

Gulf Coast Design Lab / UT Austin · 已建观鸟平台；ASLA景观专业学生奖，区别于产品设计奖。

具体痛点
湿地水沟与灌丛让原有观赏视线难以到达，公园还需要一个开展观鸟和环境教育的停留空间。
操作 → 反馈
从停车区进入 → 沿坡道上行 → 屏墙缝隙与移动过程逐步展开湿地视野 → 在平台观察、听取环境讲解。
值得借鉴
将可达性、视线和学习过程一起组织；近处草本生境也成为可被注意和讲解的对象。
设计门槛
观察高度、视线、坡道、多人停留和湿地选址必须共同设计，且需要管理人员与生态专业人员参与。
与松雅湖的关系及AI证据

最贴近“观鸟设施＋自然教育”的场景。原页没有提供降低鸟类惊飞率的量化实验，不能把屏墙直接写成已验证的隐蔽效果。

空间与身体移动形成交互；没有AI或自动监测依据。

B05

延伸 · 专业拍鸟的追踪操控

Gitzo Fluid Gimbal Head

iF DESIGN AWARD 获奖项目；奖年未核

Lino Manfrotto / Gitzo · 实体摄影附件；适合专业设备操控参照，不作为普通家庭的默认需求。

具体痛点
长焦设备较重，持续平衡设备并平顺跟随移动对象有困难；这是官方项目页明确针对的鸟类与野生动物观察任务。
操作 → 反馈
将设备装在平衡支撑上 → 手动平移 / 俯仰跟随 → 流体机构吸收振动、调节运动手感。
值得借鉴
通过支撑与阻尼降低操作者持续保持画面的负担，保留直接手动控制。
设计门槛
负载、平衡、阻尼和锁止需要与镜头匹配；材料与机械精度是门槛。
与松雅湖的关系及AI证据

可以借鉴公共观察设备的支撑与转向手感；本例没有自动追鸟依据。

手动追踪与机械 / 流体反馈，未核AI。

B06

延伸 · 人鸟共存的系统边界

Migratory Bird Networks & Urban Networks: From Conflict to Coexistence

ASLA 2024 Student Awards · Honor Award, Analysis & Planning

Gachon University 学生团队 · 韩国仁川延寿区的分析与规划方案；不是已落地智能产品。

具体痛点
城市建设与潮滩生境缩减使候鸟活动网络受到影响，城市文化设施与湿地教育之间也缺少关联。
操作 → 反馈
方案先恢复生境条件 → 设置观鸟平台与生态教育节点 → 将公众活动和城市生态网络连接。
值得借鉴
先确定鸟类需要怎样的生境，再安排人的到达与学习；没有将“提高到访人数”作为唯一目标。
设计门槛
需要跨尺度的生态、土地、水文与运营协作，适合用来限定产品的服务边界。
与松雅湖的关系及AI证据

借鉴保护、体验和教育的组织逻辑；仁川潮汐条件和规划效果不能直接套到松雅湖，也没有已建成效验证。

规划中有环境监测设想；未确认AI决策或自动鸟种识别。

05 / 选题推演

最值得先验证的一句话

新手如何在不靠近、不频繁中断观察的条件下，与同伴找到同一目标，并理解观察证据？

以下为本次基于案例与文献提出的选题，不是已完成的松雅湖需求调查，也不是获奖产品的现成功能清单。

优先考虑：面向亲子与新手的低干扰共享观鸟交互

用户任务
在管理允许的观察点，让几个人较快找到同一目标，再理解少量可见的行为与特征。
可验证的设计
将实体朝向 / 转动、共享画面与简洁提示结合；AI仅在看清证据之后辅助解释。
必须跨过的门槛
共享目标的定位与同步、户外可读性、长幼身高差、低注意力负担，以及生态边界。
首轮原型
先用借来的望远镜、手机共享画面和可调支架验证流程；首轮不需要自研光学或训练大模型。
趋势对应
可对应情境交互、多模态反馈与包容性设计。实体交互或身体参与不自动等于具身智能。

其次：围绕可见证据的AI自然观察学习辅助

用户任务
帮助用户从“它叫什么”走向“我根据什么认出来、它在做什么”。
可验证的设计
呈现候选种、可核对特征和无法判断的原因；支持请讲师确认与修正记录。
必须跨过的门槛
远处小目标、相似鸟种、遮挡和图像质量；错误识别如何被发现与修正，比增加对话功能更关键。
首轮原型
用经本地专家核对的有限鸟种样本做任务原型，比较名称提示、特征提示与证据复核三种流程。
趋势对应
可对应可解释AI、人的复核与自然教育。此处是选题推演，并非上述获奖产品均已具备。

有场地合作后再考虑：随保护边界调整的观察节点服务

用户任务
帮助公众知道哪里可以观察、为什么某些区域需要保持距离。
可验证的设计
把季节性管理信息、观察点和解释内容接入游客到达流程。
必须跨过的门槛
依赖真实管理规则、生态监测与运营维护；不能由设计者自行设定鸟类安全距离。
首轮原型
先做路线和节点服务原型，借助管理者审核情境；未经许可不在湿地设置互动装置。
趋势对应
可对应服务设计与人和自然共同受益的设计；不能只用游客参与量评价成效。

第一次到松雅湖，先完成这4件事

  1. 找管理人员或自然学校核对当前开放观察点、活动规则与季节性变化。
  2. 跟随一组亲子或新手，记录从找鸟到理解鸟的完整过程，不预设他们需要AI。
  3. 比较独自观察和两人共同观察，确认“找不到同一目标”是否构成明显困难。
  4. 分别访谈讲师、普通游客与管理者，确认学习价值、使用负担及保护要求能否兼容。
