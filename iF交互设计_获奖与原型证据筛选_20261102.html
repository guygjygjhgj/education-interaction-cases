IP01 · AI音乐教育 · 手势与多模态

ROLI Airwave

iF DESIGN AWARD 2026 · Product Design / Musical Instruments

iF产品设计记录与厂商2026获奖说明交叉核对。产品页ID为752394；同名包装获奖页752403另列，未用于替代产品奖。

原型 / 运行依据：官方说明手部追踪、键盘输入、语音交互与练习反馈；支持网站另有Airwave Player / Control更新记录和故障处理条目。

不止外观或生图：公开资料对应硬件、应用与操作维护。这里核的是可运行产品与公开功能记录，未亲手测试准确率。

实现阶段
已开发的硬件与软件系统；AI Music Coach目前官方标为beta。
具体痛点
数字音乐学习若只检查音符，难以回应指法和手部动作；创作时，部分身体动作也缺少连续的声音表达通道。
交互过程
红外相机追踪手部 + 键盘输入 + 语音提问 → 练习反馈；创作模式把手部追踪数据转成MPE控制。
智能功能依据
官网明确手部追踪和对话式AI；beta功能、硬件功能与教学效果分开判断。
设计门槛
遮挡与识别失败反馈、动作和音色的映射、时延、AI反馈是否可理解，以及练习进步怎样测量。
与你的方向关系
直接适合音乐教育、多模态与手势交互研究；迁移到城市声景时，只借鉴动作到声音的映射，不声称它解决城市噪声。
可继续研究
可收敛为“面向学习者的手势反馈如何支持自主纠错”，或“动作—声音映射如何降低音乐表达门槛”。

厂商的学习价值表述不等于独立教育成效实验；未将所有市场宣传作为已验证结论。

IP02 · AI素养教育 · 具身交互 · 小学至高中

UGOT robot / 优必选

iF DESIGN AWARD GOLD · Product Design / Computer；2024获奖由公司年度报告补证

iF原页有Gold评语，明确获奖对象是模块化AI教育机器人；公司2024年度报告另有该奖项记录。

原型 / 运行依据：官方产品资料展示多种实体形态，说明免工具旋钮锁拼搭、视觉与语音等能力；产品手册明确面向不同学段。

已有整机与课程操作资料。未以其他型号机器人的SDK、视频或测试结果替代UGOT自身证据。

实现阶段
可拼搭的机器人系统；官方有产品页、UGOT产品手册与软件操作入口。
具体痛点
搭建与调试的负担可能挤占感知、决策和编程学习；学生也需要看懂输入如何变成机器人行动。
交互过程
搭建形态 → 图形化或编程配置 → 机器人感知与执行 → 观察结果并修改。
智能功能依据
iF评语列出视觉算法和语音识别；厂商产品页说明手势、姿态等识别能力。不据此推定所有宣传能力都经过独立评测。
设计门槛
拼搭状态是否清楚、识别到什么是否可见、执行失败如何恢复，以及小学生和高中生的操作层级如何区分。
与你的方向关系
iF页目标群体包含10岁以上及学校；官方手册覆盖小学、初中、高中。适合作为AI与机器人教育的直接案例。
可继续研究
可研究“让学生看懂机器人为什么这样行动”的可解释反馈，或不同学段的可供性与调试交互。

这是AI与机器人学习系统，不是已经核实的CoStage式故事共创系统；具身交互也不自动等于自主具身智能。

IP03 · 概念设计原型 · 声景与触觉沟通

Waveband / Kristjan Juks

iF学生获奖项目；作者作品集将Waveband获奖列于2020年

iF项目页有评语与学校、设计师信息；作者个人作品集提供获奖年和项目原始过程。

原型 / 运行依据：设计师原始项目明确记录Arduino、10 mm振动马达、磁铁和材料试样，并展示3D打印及目标使用者验证过程。

可核的是振动反馈、佩戴与触点等原型探索。完整无线声源识别、续航和防水等最终产品设想未据此全部确认为实现。

实现阶段
毕业设计概念，存在基础功能部件原型与实体试验；不是已核完整量产产品。
具体痛点
声音呼唤并非人人都能接收，听觉条件和愿意接收的信息量也不同；提醒方式需要给使用者选择。
交互过程
触觉提醒与可穿戴交互 → 使用者辨认振动并选择参与方式 → 调整触点和反馈编码。
智能功能依据
未核AI。它的价值是触觉转译与参与式原型方法，不加上自动声源识别或大模型标签。
设计门槛
不同振动位置是否能区分、佩戴触感是否稳定、编码是否可学，以及误提醒造成的负担。
与你的方向关系
适合声音交互与包容性设计；向听障青少年自然教育迁移需要与该人群重新共创。此为历史方法案例。
可继续研究
可研究“哪些声景信息值得转为触觉”，并在功能原型阶段比较触点、节奏与辨认表现。

原型和用户反馈记录不能证明脑科学疗效，也不能代表所有听障群体的偏好。

IP04 · 环境数据交互 · 历史产品方法对照

Eve Weather

iF获奖记录 · Product Design / Building Technology；奖年本轮未核

iF获奖对象为天气站。原页的2021是上市字段，本次不把它改写为获奖年。

原型 / 运行依据：厂商9页指南有传感器、屏幕、配对操作、当前与历史数据展示和天气趋势说明。

硬件与操作流程有公开文档，已超过仅概念图的证据范围；未独立测试测量精度。

实现阶段
实体天气站与配套App；采用2021厂商指南核对当代产品，避免混入后续Matter版本功能。
具体痛点
单一时点的数字难以帮助普通使用者理解一段时间内的变化。
交互过程
采集温湿度与气压 → 设备显示当前值 → App查看历史变化 → 用趋势信息支持日常判断。
智能功能依据
未核AI；属于传感、数据可视化和语音查询交互。不能用“智能天气站”直接推定AI生态预测。
设计门槛
测量误差、图表尺度、采样和刷新频率，以及让使用者区分实测值与推断趋势。
与你的方向关系
给环境数据课题提供实际交互链参照。原产品不是专门面向学生的生态科普工具。
可继续研究
先验证学生是否能通过同一组真实记录解释变化，再决定是否增加生成视觉。

历史方法对照，不用作2026年前沿AI概念的证明；本轮不比较其精度优劣。

IP05 · 实体阅读与视觉识别 · 历史产品方法对照

Luka Reading Robot

iF获奖记录 · Product Design / Babies & Kids；奖年本轮未核

iF原页确认该读书机器人与Ling Technology，未把后续Luka Hero或其他型号功能并入。

原型 / 运行依据：厂商App下载页明确说明与Luka Reading Robot配套；另有制造商监管申报使用手册存档，包含设备操作。

可核实体书、摄像头识别与语音反馈的产品关系；不据此承诺当前所有地区的服务可用。

实现阶段
实体读书机器人及伴随App。iF原页上市字段为2017，属于历史交互方法参照。
具体痛点
儿童操作纸质书时，需要随翻页响应的辅助，重复菜单操作会打断实体阅读。
交互过程
翻动纸质绘本 → 视觉识别页面 → 朗读反馈 → 配套App管理。
智能功能依据
iF原页明确计算机视觉识别；未确认该获奖版本含LLM共创。
设计门槛
光照、遮挡、绘本版本与识别失败反馈；辅助朗读与主动创作应分别设计和评价。
与你的方向关系
原页面向2—8岁，不扩写为高中产品。本次仅用于对照实体操作怎样成为自然输入。
可继续研究
可借鉴“保留纸质操作”的反馈方式，不能直接替代面向小学中高年级的故事共创研究。

历史方法对照，不作为最新AI共创产品或长期阅读改善的证据。
