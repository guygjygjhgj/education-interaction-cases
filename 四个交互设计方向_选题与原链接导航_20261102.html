01 / RESEARCH SCOPE

先选一个有边界的研究问题

以下趋势是依据本轮文献与案例所作的设计研究归纳，没有把少量实例当作统计性行业预测。

方向候选题需要解决的关键困难先验证什么
环境数据驱动的生态交互面向中小学生的湿地环境变化多模态认知交互设计环境数值、现场感受与生态意义分离：看到数据变化，未必理解它代表什么，也容易把同时发生误当因果。用同一数据比较两种反馈；检查趋势读取、证据辨认与迁移到新图表的解释，分开记录兴趣和理解。
环境数据驱动的生态交互面向青少年的天气—气候尺度转换与不确定性交互叙事设计实时天气、长期气候趋势与想象中的未来容易在同一视觉界面中混在一起。测试能否识别天气与气候、找出假设、解释多个结果；比较有无来源和不确定性标识的版本。
城市声景与声音交互保留环境语义的城市声景音乐化交互设计声音体验可能令人烦扰，但完全遮蔽也会损失声源、方向和地方信息；单纯加音乐不等于解决噪声问题。比较原声、固定配乐和可交互转译；分别测声源辨识、注意负担、控制感与喜好，先用录音或封闭任务。
城市声景与声音交互面向听障青少年的声景视觉—触觉转译交互设计日常声音提醒和自然教育活动常把听觉当作共同前提，而不同使用者需要的信息与参与方式并不相同。与使用者选择有限事件，比较纯图形与图形加触觉；评价辨识、误报负担、控制感和愿意持续使用的场景。
儿童与AI的具身故事共创面向小学中高年级的儿童主导型AI—机器人故事共创交互设计AI能快速产出完整故事，但儿童的想法可能被生成结果替代；角色、动作与情节之间也可能脱节。固定任务与材料，比较AI直接给答案、AI追问和有限建议；记录儿童自主决策、修改、叙事连贯与控制感。
儿童与AI的具身故事共创面向祖孙共同创作的口述故事AI可视化与协同修订交互设计口述转成图像时可能丢掉原意，生成画面又容易盖过讲述者记忆；双方缺少共同确认与改写的对象。比较自动生成与共同修订两种流程；测原意保留、错误发现、双方参与和修改负担，另看是否愿意再次使用。
动物感知与多物种科普面向儿童自然教育的鸟类色彩视觉差异可解释交互设计人容易用自己的色彩经验理解动物；“动物滤镜”又可能让孩子把艺术颜色误认为科学事实。比较普通图文、无解释滤镜、有图例和可操作证据的版本；测原理解释、错误信念和新情境迁移。
动物感知与多物种科普面向青少年的候鸟夜间光环境风险交互科普设计观众可能知道“保护鸟”，却难以把夜间亮灯等日常行为与候鸟风险建立具体联系。后半句是需要现场核查的认知问题。比较环保口号、图文与条件对照交互；检查能否解释机制、识别局限，以及是否选出有依据的行动。

不是所有题目都需要AI。实时数据、AR、触觉反馈和身体操作分别有自己的交互价值；只有证据明确时才把原作标为AI。

FT01 · 候选研究题 / 本次推演

面向中小学生的湿地环境变化多模态认知交互设计

数据可理解化、多模态信息表达、在地自然教育

对象与场景
小学高年级至初中；自然教育活动或湿地观察后的整理环节。年龄为建议研究范围，不是原作样本。
具体痛点
环境数值、现场感受与生态意义分离：看到数据变化，未必理解它代表什么，也容易把同时发生误当因果。
证据到哪一步
数据解释与编码有FP06、FP07的方法依据，FC01提供公众数据使用案例；学生具体误解及频率需在松雅湖或洋湖现场验证。
研究问题
同一组真实环境记录，用曲线、可操作实体或声画联动呈现，哪种能支持学生解释变化并说出不知道的部分？
交互过程
选同一地点与时段 → 比较真实记录 → 调整呈现或有依据的情境参数 → 查看变化与证据 → 用自己的话解释。
AI应承担什么
可用于检索有出处的解释、按年龄改写与生成追问；先用规则映射验证交互价值。实时数据接入本身不是AI。
设计门槛
数据缺失、传感器误差、时间尺度和映射关系；要避免把变化的“数字生物”误当真实生态预测。
选题如何验证
首轮验证
用同一数据比较两种反馈；检查趋势读取、证据辨认与迁移到新图表的解释，分开记录兴趣和理解。
成立条件
若无法取得有出处的环境数据，或只能证明画面好看，就暂不能论证生态教育价值。
资源与可行性
可先用历史数据与桌面原型；持续自动监测是后续工程工作。

FT02 · 候选研究题 / 本次推演

面向青少年的天气—气候尺度转换与不确定性交互叙事设计

可解释交互、数据来源透明、气候传播

对象与场景
初中至高中；科学传播、地理学习或公共环境教育。
具体痛点
实时天气、长期气候趋势与想象中的未来容易在同一视觉界面中混在一起。
证据到哪一步
WMO区分天气与长期气候；截图1展示的是实时数据驱动创作。这里把误解风险提出为研究假设，未断言原作误导观众。
研究问题
怎样让使用者看懂“当前记录”“模型假设”“艺术生成”分别是什么，并能比较不同时间尺度？
交互过程
切换小时、季节与多年尺度 → 看到样本来源和范围 → 修改一个有说明的假设 → 对照多个结果 → 返回证据。
AI应承担什么
可生成有标记的叙事变体与提问；气候计算必须使用经核验的数据和模型，不能让图像生成器充当预测模型。
设计门槛
尺度切换、不确定性编码、变化可追溯性，以及让使用者区分“可想象”与“有证据支持”。
选题如何验证
首轮验证
测试能否识别天气与气候、找出假设、解释多个结果；比较有无来源和不确定性标识的版本。
成立条件
如果没有科学模型支持，应把作品定位为思辨或艺术叙事，并评估它引发的问题理解。
资源与可行性
可从时间轴和交互叙事验证，成本可控；科学模型校核需要合作资源。

FT03 · 候选研究题 / 本次推演

保留环境语义的城市声景音乐化交互设计

声音交互、情境感知、生成式媒介、具身控制

对象与场景
步行者或参与声音探索的青少年；先选一个低干扰、可重复的体验任务。
具体痛点
声音体验可能令人烦扰，但完全遮蔽也会损失声源、方向和地方信息；单纯加音乐不等于解决噪声问题。
证据到哪一步
UNEP把城市噪声列为环境议题；FP08提供注意与声化的实验方法，FC03提供AI声音生成UX参照。目标场景仍需现场测听与访谈。
研究问题
哪些声学信息可以被转译为音乐，哪些语义和方向线索需要保留，使用者又能否自主切回原声？
交互过程
采集或播放经许可的环境音 → 分类并显示不确定项 → 选择转译程度 → 以行走或手势调节 → 对照原声与音乐。
AI应承担什么
可承担环境声分类和生成性编排；应与规则音频处理对照，检查AI是否带来可说明的价值。
设计门槛
混合声源识别、时延、音乐映射的可解释性、原声与生成声的控制，以及对有意义线索的保留。
选题如何验证
首轮验证
比较原声、固定配乐和可交互转译；分别测声源辨识、注意负担、控制感与喜好，先用录音或封闭任务。
成立条件
如果效果仅是更好听，应定位为声景体验或艺术表达；不能写成实际降噪或健康治疗。
资源与可行性
音乐与信号处理门槛较高；先验证少量声源与单一动作的映射。

FT04 · 候选研究题 / 本次推演

面向听障青少年的声景视觉—触觉转译交互设计

包容性设计、跨感官信息转译、参与式设计

对象与场景
愿意参与声音探索的听障青少年及同伴；需要与目标使用者共同定义信息需求。
具体痛点
日常声音提醒和自然教育活动常把听觉当作共同前提，而不同使用者需要的信息与参与方式并不相同。
证据到哪一步
FC04有面向听障群体的参与式设计记录；FP06支持跨感官编码的设计分析。科普活动中具体遗漏的信息仍待共创调研。
研究问题
哪些声音线索值得转为图形或振动，怎样让使用者选择信息量，并知道系统没有识别清楚什么？
交互过程
本人选择关注的声音事件 → 屏幕提示声源与方向 → 触觉表达节奏或提醒 → 本人确认、关闭或修正。
AI应承担什么
可以辅助特定声源分类；视觉与振动反馈本身不是AI。不要默认需要识别和推送所有声音。
设计门槛
编码是否可学、个体触觉差异、多事件区分、识别出错后的反馈；不能替参与者预设“应该听到什么”。
选题如何验证
首轮验证
与使用者选择有限事件，比较纯图形与图形加触觉；评价辨识、误报负担、控制感和愿意持续使用的场景。
成立条件
没有稳定的目标使用者参与时，这个题目的需求真实性与评价都会受限。
资源与可行性
电子原型可做得很小；主要门槛是共同研究与有效编码。

FT05 · 候选研究题 / 本次推演

面向小学中高年级的儿童主导型AI—机器人故事共创交互设计

人机共创、儿童主体性、具身交互、机器人执行

对象与场景
小学中高年级；课外创作、图书馆活动或家庭合作叙事。建议年龄不能冒称CoStage原作样本年龄。
具体痛点
AI能快速产出完整故事，但儿童的想法可能被生成结果替代；角色、动作与情节之间也可能脱节。
证据到哪一步
CoStage直接提供具身故事共创的比较研究；FP02与FP05提供叙事和人机分工视角。AI接管程度的影响是待验证变量。
研究问题
在何时由AI提问、给备选或执行动作，才能让儿童保留角色目标、情节选择与修改权？
交互过程
儿童定角色与目标 → AI给有限提示 → 儿童摆位、录动作或发指令 → 机器人执行 → 对照意图并修改。
AI应承担什么
承担有范围的语义理解、提示与动作草案；机器人执行与状态反馈应可检查，儿童能拒绝或撤回。
设计门槛
叙事文本与机器人行为一致、动作失败可恢复、儿童能理解控制权，以及跨多次活动的评价。
选题如何验证
首轮验证
固定任务与材料，比较AI直接给答案、AI追问和有限建议；记录儿童自主决策、修改、叙事连贯与控制感。
成立条件
若只是复现CoStage舞台形式，创新不足；应明确改变了哪个交互变量、解决了哪一类创作困难。
资源与可行性
机器人、定位与生成时延增加工作量；可先用单机器人与有限动作集。

FT06 · 候选研究题 / 本次推演

面向祖孙共同创作的口述故事AI可视化与协同修订交互设计

多模态共创、代际共融、可解释与可修订AI

对象与场景
祖辈与小学儿童共同参与；家庭故事、地方生活记忆或口述文化记录。
具体痛点
口述转成图像时可能丢掉原意，生成画面又容易盖过讲述者记忆；双方缺少共同确认与改写的对象。
证据到哪一步
FC05提供语音到图像再到实体页面的获奖概念。丢失原意和修订负担在此作为需要访谈验证的设计假设。
研究问题
怎样让讲述者和儿童都能指出“这不是我想表达的”，并保留原话、修改和AI补充的区别？
交互过程
分段口述 → 生成有来源标记的图像草稿 → 双方圈选或语音纠正 → 对照原始录音 → 形成可修改的实体页面。
AI应承担什么
语音识别、分段和图像草稿；真实事件与人物不能由AI自行补写后伪装成记忆。
设计门槛
口音、停顿与叙事结构，图像纠错的操作成本，双人轮流编辑和内容控制权。
选题如何验证
首轮验证
比较自动生成与共同修订两种流程；测原意保留、错误发现、双方参与和修改负担，另看是否愿意再次使用。
成立条件
生成图像好看与代际关系改善需要分开评价；不能直接把此题定义为心理治疗。
资源与可行性
可先做语音、图像和纸页组合；难点在协作过程而非只接入生图接口。

小学高年级至初中；自然教育、科学馆或湿地观察前后的科普环节。
具体痛点

交互过程

成立条件
拿不到多通道硬件时，可先用许可明确的科研样例；不能声称普通摄像头已实时复原鸟类视野。
资源与可行性

带着这些问题进入现场

  1. 让参与者完成一个真实任务，记录他在哪一步误解、放弃或转向别人求助。
  2. 先确认需要理解或表达的信息，再选择视觉、声音、触觉或实体动作。
  3. 保留一个简单可比较的版本，检查AI、模态增加或机器人加入后到底改善了什么。
  4. 把兴趣、理解、控制感、长期使用与实际行为分开评价。
