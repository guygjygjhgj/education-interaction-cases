01 / PROBLEM FRAME

先把原话、转述与推断分开

芒果TV官方页面介绍为邀请久未见面的朋友集体旅行，关注人际疏离。用户说的《后会有期》应为此节目。

本次核对官方公开介绍，未观看完整正片，未核对某一集具体对话。节目作为问题线索，不用于判断嘉宾动机或证明社会现象发生率。

芒果TV官方节目介绍 ↗
原意与表达意愿文字、声音与背景转述、记忆与概括接收者解释回应、澄清或回避

原意 → 表达 → 转述与记忆 → 接收解释 → 回应与修正，是本次组织研究材料的框架。它不是节目人物分析，也不是一套临床诊断。

虚构示例 · 不是节目情节或研究数据

同一件事，三个不同层级

A的原话
“这周我想一个人待着，周末再联系。”
B的概括
“她最近不太想聊天。”——时间、后续联系安排被弱化。
C加入的判断
“她不想理你。”——新增了针对某个人的意图归因。
接收者的推断
“她是不是对我有意见？”——需要向本人核对，不能直接视为事实。

不是每次转述都会这样变化。设计应让人识别变化，而不预设转述者恶意或要求大家必须达成同一观点。

02 / COMMUNICATION ISSUES

8类问题，分别发生在不同环节

下列对话示例均为虚构说明，不是节目台词或论文中的原始实验材料。

M01

表达回避：重要的话没有说出来

“我不同意，但怕说了伤感情，就让共同朋友去说。”

机制 / 分析
对对方反应的预测影响表达意愿；转述有时替代了直接确认。
交互切入
让人区分“对方实际反应”与“我预测的反应”，提供低压力、可退出的表达入口。

不以研究均值要求所有人开口，更不把拒绝沟通认定为错误。

CP04 · 提异议者高估异议接收者的消极反应

M02

共同背景不同：默认对方知道我知道的事

“我以为你知道我这周很忙，所以没解释为什么没赴约。”

机制 / 分析
表达者与接收者拥有不同知识、经历和注意焦点。
交互切入
把各自已知与未知的信息显现出来；用具体追问代替猜测。

观点采择有任务条件，不把它概括为所有人都缺乏共情。

CP03 · 语言加工过程中的观点采择及其认知机制

M03

转述重构：条件丢失、概括替代原话

“这周想独处，周末联系”被概括成“她不想聊天”。

机制 / 分析
记忆、概括和再次表达可以改变细节、确定程度与范围。
交互切入
对照不同版本，标出删去的时间、对象、条件及新加入的推测。

信息改变不自动等于恶意，也不必然总向负面改变。

CP01 · 系列再生法：探讨刻板印象的新思路

M04

来源混合：个人判断变成“对方就是这么想的”

“我猜她在生气”被接收为“她亲口说对你不满”。

机制 / 分析
这是本次从转述任务中拆出的设计问题：说话者、原话与转述者推断需要区分。
交互切入
保留信息出处与不确定性；分开“原话”“我的理解”“尚待确认”。

这里没有将所有来源混淆都归为同一已验证心理效应。

CP01 · 系列再生法：探讨刻板印象的新思路

M05

语气误读：文字承载不了全部表达线索

同一句“你忙吧”，可能是体谅、失落，也可能被读成讽刺。

机制 / 分析
文字缺少部分语调、重音和即时反馈，发送者又可能高估语气传达效果。
交互切入
提示多种可能理解，让发送者确认语气，让接收者有澄清入口。

语音或视频也可能产生误解；增加模态并不自动得到真实意图。

IR01 · Egocentrism Over E-Mail: Can We Communicate as Well as We Think?

M06

模糊处被补全：解释走在事实前面

从“她没回复”推断为“她故意冷落我”。

机制 / 分析
事实不足时，人会作解释；负性解释的发生条件可从相关任务研究中寻找线索。
交互切入
让人看见自己补上的解释，并保留其他待验证的可能。

网络突发事件的负性偏向不能直接当作所有友情中的固定规律。

CP02 · 网络突发事件中的负性偏向：产生与表现

M07

对话后的记忆偏移：不断重复同一版本

共同回忆一段经历时，有人反复只提其中几件事，另一些细节没有被再次谈起。

机制 / 分析
互动中的选择性提取，在特定条件下影响听者对其他内容的记忆。
交互切入
允许回看多方记录、补充遗漏与修正；同时显示尚未达成一致之处。

不要把单次主观回忆差异解释为谁在撒谎。

CP05 · 情绪效价和动机强度对社会分享型提取诱发遗忘的影响

M08

缺少理解确认，或AI代写引入新的中介

一方以为解释完成；另一方仍没理解。AI润色后，话变顺了，立场也可能改变。

机制 / 分析
需要区分复述确认、理解修正、AI修改与本人认可的表达。
交互切入
呈现“我听到的是……”并允许对方纠正；AI修改需可见、可拒绝、保留原意。

澄清理解不等于赞同或和解；真实利益、价值和边界冲突仍可能存在。

CC01 · 认识现象＋练习理解确认

A Toy for Empathy / Empathy Toy

Core77 Design Awards 2014 · Educational Initiatives · Professional Notable

已有产品与引导式工作坊；Notable为表彰级别，不写成最高奖。

具体痛点
双方拥有的信息或感知条件不同，容易把“我描述清楚了”误当成“对方理解了”。
操作与反馈
拼图创建者准备形状 → 引导者用语言描述 → 拼装者触摸、提问和拼装 → 对照结果、讨论沟通方式。不同玩法可改变蒙眼条件。
值得借鉴
让误差产生可观察的结果；失败成为复述、具体提问与协作的材料。
设计门槛
需要设计有意义的信息差和复盘，不把快完成当作沟通能力提升；单次体验不能证明长期关系改善。
适用边界与AI依据

本次最贴近“让人意识到沟通误差”的案例；不是专门追踪朋友之间的真实转述。

实体、触觉、语言和协作；未核AI。

CC02 · 辅助表达自身状态

INSIDEOUT

iF DESIGN STUDENT AWARD

具体痛点

CC03 · 减少含糊预期与日常协调冲突

COUS — Shared Living Management Application

iF DESIGN STUDENT AWARD

具体痛点

降低语言转换的操作负担；同时提示研究者关注机器怎样重组人际信息。
设计门槛
译文通顺、忠实原意与关系中的恰当表达并非同一指标；仍需本人核对语境和立场。
适用边界与AI依据

解决语言转换的一部分困难，不是读心、关系调解或事实真伪裁判。

CC06 · 共同文件与跨语言协作参照

Virtual Personal Assistant / Samsung SDS

Red Dot Award: Design Concept 2019 · Best of the Best

移动端AI协作概念方案；不是已验证朋友关系修复的产品。

具体痛点
协作双方可能依据不同信息、不同语言或不同版本工作，需要建立共同参照。此为依据官方功能提炼的问题。
操作与反馈
在移动协作流程中共享信息 → 实时翻译与同时编辑文档 → 围绕共同内容继续工作。
值得借鉴
把信息放到可共同查看和操作的对象上，减少仅凭各自记忆转述的依赖。
设计门槛
需要说明谁修改了什么、哪些表达来自本人；翻译与共享文档不能替代对意图的确认。
适用边界与AI依据

适合借鉴共同参照与协作流程；官方“减少误沟通”的描述没有提供长期人际关系验证。

红点页明确AI工作流、实时翻译和同时编辑；没有据此确认读心或自动判断对错。

07 / DESIGN SCOPE

怎样形成非空间的设计学课题

交互产品与沟通辅助

设计任务
让原话、转述、个人解释和待确认内容以可区分的形式出现；支持追问、复述、修正与本人认可。
可用媒介
桌面实体工具、双人 / 多人协作媒介、App或聊天辅助界面。
如何检验
内容关键条件保留、来源辨识、澄清质量和操作负担。

信息可视化与交互叙事

设计任务
让人看见不同版本之间删掉、增加或改变了什么，理解信息传播过程。
可用媒介
虚构材料的版本对照、交互时间线或传播链可视化。
如何检验
能否区分事实与归因、能否在新材料中识别同类变化。

学习游戏与反思性设计

设计任务
用可观察的协作结果揭示信息差，再组织复盘与角色互换。
可用媒介
桌面游戏、拼装工具、屏幕互动或实体与数字结合的学习产品。
如何检验
理解校准与迁移，不以游戏速度或好感单独证明沟通能力。

评价“理解改善”时，分别看这些结果

  • 信息准确：时间、对象、条件、否定与确定程度是否被保留。
  • 来源清楚：哪些来自原话，哪些来自转述者或接收者的推断。
  • 理解可修正：接收者复述后，原表达者能否指出偏差并补充。
  • 判断有校准：自认为理解的程度，是否与实际理解相匹配。
  • 表达自主：AI修改是否保持本人的立场、语气与承诺，是否容易拒绝或修正。

本题的设计难点，是让人愿意核对、能够修正，并保有自己的表达。对方同意、关系和好和信息被准确理解应分别判断。

08 / RESEARCH QUESTIONS

可以继续验证的交互研究问题

以下为本次研究推演，尚未定为具体产品方案。需要先确定人群、关系场景和当下困难，再选取原型形式。

认识型：让传话中的变化可被看见

研究问题
怎样让参与者区分原话、转述和自己补充的解释？
参考方法
参考系列再生法，用虚构材料比较逐字、概括与加入推测的版本；把删去的条件和新增的判断显现出来。
检验什么
检查参与者能否指出哪些是原始信息、哪些是推断；观察离开体验后能否迁移到新材料。

这是本次提出的研究机会，不是已检索到的获奖产品。避免预设每一轮都必须更负面。

练习型：把“我懂了”改成可以纠正的复述

研究问题
共享任务中，怎样降低请求澄清与纠正误解的负担？
参考方法
对照仅单向描述、可自由提问、可复述确认的任务条件；参考Empathy Toy和自然会话修正研究。
检验什么
比较任务理解一致程度、澄清质量和完成负担；同时观察参与者是否愿意纠正对方。

一次游戏表现不等于长期共情或关系质量，测试需要复盘和后续材料。

辅助型：AI润色怎样保持本人立场

研究问题
AI辅助表达时，怎样让人知道哪些语气、承诺、确定程度被改动？
参考方法
保留原文与修改对照，由本人选择、拒绝和确认；把“更客气”与“更忠实表达我”分别评价。
检验什么
比较本人认可度、接收者理解和原意保留；评估AI是否引入新的承诺或归因。

这是研究问题，不把AI设为真相裁判，也不自动替用户发送消息。

理解对方、赞同对方、接受请求和恢复关系是不同结果。信息澄清不能消除所有真实分歧，设计需要保留不回应、不同意和结束互动的空间。

较合适的首轮研究对象可以是：同伴共同完成任务、宿舍协商日常安排、或虚构材料的多人转述。需要验证的核心是“理解是否更一致”，而不仅是“话是否更好听”。
